# Input Videos Directory

Drop any surveillance, CCTV, or test video clips into this directory (`inputs/`).

### Supported Formats:
- `.mp4`, `.avi`, `.mov`, `.mkv`, `.webm`

### How to Run:
```bash
# Process a specific video in this folder:
python detect.py --input inputs/my_video.mp4

# Or simply run detect.py, which automatically picks up videos found in inputs/:
python detect.py
```
